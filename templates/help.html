使用说明

第一次使用请先读完「录音权限」一节

近似音区分
  1. 选择一组近似音，例如 sheep-ship（/iː/ 与 /ɪ/）。
  2. 填空题量（默认取 设置 里的值），音频性别不用选。
  3. 每题屏幕上出现两个单词，分别标号 1 和 2，系统随机朗读其中一个，男声或女声也是每题随机抽。
  4. 在限时内点屏幕上的 1 号 / 2 号卡片作答（电脑上也可以按键盘 1 2）； 超时记为「无回答」，判完立刻进入下一题。
  5. 没听清可以点「再听一遍」重播当前这题，重听不额外加时；判完和进入下一题时按钮会暂时变灰， 免得误听到下一题的发音。
  6. 选「句子练习」时播放的是含该词的整句（教材 4A），屏幕上仍然只给句中变化的那两个词，答完和结果页能看到原句。

结束后会显示总题数、正确数、错误数，并可逐题回看当时听到的音频。

看读译
  1. 填空题量和三段时长后开始（这些框的默认值取自 设置， 想固定住自己的节奏就去那儿存一份），系统从词库（共 {{ word_count }} 个单词）随机抽词。
  2. 第一轮：每个单词在屏幕上展示你填的第一轮时长（默认 1.5 秒），同时开始录音，请大声朗读。
  3. 第二轮：每个单词展示你填的第二轮时长（默认 5 秒），不录音，用键盘输入它的中文译文（任写一项即可）。
  4. 时长填出格的值会被夹回上下限：第一轮 0.3~20 秒、第二轮 1~60 秒、题目之间的停顿 0~3 秒。
  5. 结束后逐题显示译文对错与正确译文，并可回放你的朗读与标准发音对比。
听读写
  1. 填空题量和三段时长后开始（默认值同样取自 设置， 「边播边录」开关也在那儿记着），系统从词库（共 {{ word_count }} 个单词）随机抽词并播放真人朗读； 男声、女声每题随机抽一个，不能自己挑——练的是听出单词，不是听惯某个人的音色。
  2. 第一轮（默认「边播边录」）：单词音频一响就同时开录，跟着标准音念； 音频放完后再走满「第一轮」里填的秒数，让你把这个词独立念完整—— 每词的录音长度就是「音频本身 + 你填的时长」。想让尾巴长一些就把第一轮调大些； 关掉这个开关就回到以前的「先听完、再跟读」。
  3. 边播边录会把标准音一起收进「我的朗读」：戴耳机最干净，外放时桌面 Chrome / Edge 的回声消除能压掉大半，但仍能听到一点底音。判分看的是第二轮键入的拼写，与录音方式无关。
  4. 第二轮：再播一次音频后空出你填的第二轮时长（默认 5 秒），输入该单词的正确拼写。
  5. 全程不显示拼写；三段时长的上下限与看读译一致，填出格会被夹回。
  6. 结束后逐题显示拼写对错与正确释义，并可对比录音；结果页的参数徽章会写明这一轮是 「边播边录」还是「先听后录」。
录音权限
  • 首次点击录音时浏览器会弹出麦克风授权，请选择「允许」。
  • 浏览器要求安全上下文：http://localhost 可用；用 IP 从别的机器访问时 http:// 会被拒绝麦克风，需要 HTTPS 或改用 localhost。
  • 编码自动选择：优先 audio/webm;codecs=opus，其次 ogg、mp4； 都不支持时（如部分 iOS Safari）回退为自行编码的 WAV。
  • 不想授权也可以练习：录音失败只影响「回放对比」，答题与判分不受影响。
手机 / 平板上怎么用
近似音区分
  • 两张选项卡本身就是按钮，点一下就算作答，小屏上会竖着排满整行宽度，好按也不会误触。
  • 判完这一题卡片立即失效，连点不会把下一题的答案带跑。
  • 没听清就点「再听一遍」，不用等下一题去结果页回放。
听读写 / 看读译的打字环节
  • 输入框固定 16 号字，iOS 不会因为点它而把整页放大；已关掉首字母大写和自动纠错， 免得 abandon 被手机改成 Abandon。
  • 软键盘上的回车就是「提交」（按钮上写的就是这个动作），不必再抬手去点屏幕上的提交按钮。
  • 键盘弹出时页面会把输入框滚到视野中间；一题答完自动收起键盘，下一题再点一下就能继续打。
  • 手机打字比键盘慢，觉得限时不够就在练习页顶上的「练习设置」里把第二轮调大（比如 8~10 秒）。
耳机与权限
  • 推荐佩戴有线耳机：蓝牙耳机普遍有 100~300 毫秒延迟，近似音辨的就是那点差别； 听读写边播边录时，外放的读音还会被一起录进去。
  • 麦克风权限只在点「开始练习」的那一次申请，之后每题复用同一条录音通道，不会再逐题弹窗。
  • 手机上「页面正常但录不了音」，多半是地址的问题：浏览器在 http://192.168.x.x 这种局域网 IP 地址下禁止调用麦克风，得用 https:// 开头的地址 （或本机 http://localhost）打开。老师那边跑 python scripts/serve_https.py 就会打印出手机可访问的 https 地址， 第一次点「继续访问」允许即可，之后录音正常弹窗。
  • iPhone / iPad 的 Safari 不支持录音直出 MP3，会自动改用本页自行编码的 WAV，文件会大一些。
发音从哪来？近似音模块和词库里的每个单词都配了真人朗读音频， 按男声 / 女声各存一份，出题时随机播其中一个；结果页「标准发音」按钮播的就是 当时听到的那一轨。极少数新加的词还没有配套音频时，先在练习页底部的「音频导入」 里上传同名文件（如 abandon.mp3）顶上，再不行用浏览器语音合成 （Web Speech API）朗读。
